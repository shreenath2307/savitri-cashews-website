# Savitri Cashews Website

Official website for **Savitri Enterprises** — Cashewnut Factory & Shop located in Poladpur, Raigad, Maharashtra.

## Details
- **Savitri Factory & Shop Address**: Sawad, Kangule, Poladpur, Raigad, Maharashtra – 402302 ([Google Maps](https://maps.app.goo.gl/GAc5chMrwyqt8CAu8))
- **Proprietor**: Vinit Utekar
- **WhatsApp & Phone**: +91 98673 94593
- **Key Features**:
  - Interactive scroll animation showcasing the cashew processing journey from tree to jar
  - Live product catalog with multiple grades (W180, W240, W320, flavoured roasts, festival gift boxes)
  - Direct WhatsApp order & inquiry integration
  - Kitchen recipes & culinary uses (Cashew Cream, Kaju Katli, Royal Cashew Pulao)
  - Factory visit details and direct Google Maps navigation

## Project Structure
- `savitri/index.html` — Main website
- `savitri/assets/` — Frame animation sequence, images, and JavaScript libraries (GSAP, ScrollTrigger, Lenis)
